# PCD schema 1.1.0 validation snapshot

The SQL operations and manifest in this directory are copied from the
[Dictionarry-Hub/schema 1.1.0 release](https://github.com/Dictionarry-Hub/schema/tree/1.1.0).
They let generation validation run offline against the exact schema dependency
declared by the root `pcd.json`.

Update this snapshot only with an explicitly reviewed schema-pin change. The
upstream MIT license is included alongside the copied files.
